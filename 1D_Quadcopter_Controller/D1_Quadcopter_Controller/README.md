# 1D Quadcopter Altitude Control — PID

## 1. Project Overview
    This project implements a **1D altitude control system for a quadcopter** using a PID controller.

    The objective is to control the drone's vertical position along the **Z-axis** by adjusting the total thrust generated by its four motors.

## 2. System Dynamics
    The vertical motion of the drone is governed by Newton's second law:
    m a_z = T - mg

    Where:
    m = 0.468 kg Drone mass
    g = 9.81 m/s^2 Gravitational acceleration
    T=Total thrust (N)

### PID Tuning Parameters
    | Parameter | Value |
    K_p= 8.0 
    K_i=0.3 
    K_d= 6.0 

## 3. PID Control Strategy
    The PID controller calculates the altitude error between the target and actual positions to generate the required thrust correction.

    **Control sequence:**
    1. Calculate the altitude error.
    2. Calculate the PID correction.
    3. Add the correction to the hover thrust.
    4. Apply thrust saturation and actuator constraints.
    5. Send the refined thrust to the drone dynamics.
    6. Update altitude and velocity for the next simulation step.

    The controller incorporates **thrust limiting and anti-windup mechanisms** to handle actuator constraints and improve control stability.

## 4. Simulation and Visualization
    The simulation evaluates the drone's altitude response over time. Dedicated modules provide **3D animation and graphical analysis** to visualize trajectory tracking and assess controller performance.

**Project Goal:** To implement and analyze a complete 1D altitude control loop, from PID-based thrust generation to drone dynamics, simulation, and performance visualization.
